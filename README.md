# Typing-Speed-Tester
The Typing Speed Tester is a web-based application developed using HTML, CSS, and JavaScript. The project measures a user’s typing speed and accuracy by comparing typed text with a predefined sentence within a fixed time duration.

# Typing Speed Tester

## Project Overview

The Typing Speed Tester is a web application that measures typing speed and typing accuracy using JavaScript.

The user types a given sentence within a limited time, and the application calculates WPM and accuracy.


# Features

- Typing speed calculation
- Accuracy measurement
- Countdown timer
- Responsive interface


# Technologies Used

- HTML5
- CSS3
- JavaScript


# Formula

WPM = Total Words Typed / Time in Minutes
